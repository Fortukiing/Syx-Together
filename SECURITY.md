# Security Policy

Syx Together accepts network data and save files from another computer. Security problems
must be treated separately from ordinary gameplay bugs.

## Reporting

Do not publish working exploits, access tokens, Steam credentials, public IP addresses or
private saves in a public issue. After the GitHub repository is created, use GitHub private
vulnerability reporting for protocol, deserialization, file-write or remote-crash issues.

Ordinary crashes and desyncs may use the public bug template after logs are sanitized.

## Supported Version

Only the newest public Alpha release is supported. Older experimental JARs may be used to
compare regressions but will not receive separate security fixes.
